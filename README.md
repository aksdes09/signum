# SignBake

Лёгкий клиентский мод для Fabric (Minecraft 26.3), который ускоряет отрисовку текста на табличках. Аналог [Signs Faster (SF+)](https://modrinth.com/mod/sf-plus).

Ванильная игра каждый кадр заново раскладывает текст таблички и рисует минимум два треугольника на символ. SignBake один раз рисует текст стороны таблички в ячейку текстуры-атласа и дальше показывает его одним прямоугольником.

## Чем отличается от SF+

- **Шрифт не встроен.** Текст в атлас рисует сам игровой рендер шрифтов, поэтому ресурспаки со своим шрифтом, жирный/курсив, цвета, светящиеся чернила с обводкой выглядят как в ванили.
- **Никаких зависимостей**, даже Fabric API. Два миксина и четыре небольших класса.
- **Пустые стороны не рисуются вообще** (обычно это вся обратная сторона таблички).
- **Память выделяется по мере надобности:** страница атласа 1024×1024 на 210 сторон табличек, новые страницы создаются только когда кончились старые; ячейки табличек, которые не были на экране несколько секунд, освобождаются.
- **Без рывков:** за кадр запекается ограниченное число табличек, остальные пока рисуются по-ванильному.
- **Безопасный откат:** обфусцированный (`§k`) текст, символы из приватной области Unicode (ими ресурспаки рисуют картинки), нестандартно большие таблички и любые неожиданные ошибки — всё это уходит в ванильную отрисовку, а не в краш.

## Настройки

`config/signbake.properties` (создаётся при первом запуске, нужен перезапуск игры):

| Ключ | По умолчанию | Что делает |
| --- | --- | --- |
| `enabled` | `true` | Главный выключатель |
| `scale` | `1` | Пикселей текстуры на пиксель ванильного шрифта (1–4). Для HD/Unicode-шрифтов ставьте 2; каждый шаг — вчетверо больше видеопамяти |
| `maxPages` | `8` | Максимум страниц атласа (8 МБ видеопамяти каждая при `scale=1`) |
| `bakeWithShaders` | `false` | Запекать ли текст при включённом шейдерпаке Iris |

## Совместимость

- Sodium — мод его не касается.
- Iris: пока шейдерпак включён, таблички рисуются по-ванильному (шейдерпак подменяет шейдер текста, запекание под ним не проверялось). `bakeWithShaders=true` включает запекание на свой страх и риск.
- ImmediatelyFast: не включайте его `experimental_sign_text_buffering` одновременно с этим модом — это та же оптимизация.

## Сборка

Нужна JDK 25.

```
./gradlew build
```

Готовый jar — в `build/libs/`. При пуше на GitHub его собирает workflow `build` (артефакт `signbake`).

## Лицензия

LGPL-3.0-or-later. Подход «рисуем текст таблички в атлас игровым рендером» взят из экспериментальной функции sign text buffering мода [ImmediatelyFast](https://github.com/RaphiMC/ImmediatelyFast) (RK_01/RaphiMC, LGPL-3.0).

---

**English:** a lightweight client-side Fabric mod for Minecraft 26.3. The text of each sign side is drawn once into an atlas cell by the game's own font renderer and then shown as a single quad. No bundled font, no dependencies, lazy atlas pages, automatic vanilla fallback.

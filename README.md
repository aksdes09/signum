# Signum

Клиентский мод для **Minecraft 26.3 (Fabric)**, ускоряющий отрисовку текста на табличках.

Ванильная игра каждый кадр заново раскладывает текст каждой таблички и выводит минимум два треугольника
на каждый символ (у светящегося текста с обводкой — в девять раз больше). Signum один раз рисует текст
стороны таблички в ячейку текстуры-атласа и дальше показывает его **одним прямоугольником из 4 вершин**.

## Как это работает

1. Миксин в `AbstractSignRenderer.submitSignText` перехватывает отрисовку текста одной стороны.
2. При первом показе Signum рисует этот текст **ванильным же кодом** в свободную ячейку атласа
   (отдельный render pass в offscreen-текстуру, без тумана, при полной яркости). Поэтому цвета,
   жирный, курсив, обводка светящегося текста и шрифты из ресурспаков совпадают с ванилью.
3. Дальше каждый кадр отправляется один квад с UV этой ячейки. Освещение, туман и прозрачность
   применяются к кваду так же, как к обычному тексту.

Что сделано сверх простой идеи:

- **Общие ячейки для одинакового текста.** Десять табличек «Сундук» на складе занимают одну ячейку.
- **Горячий путь без поиска.** Ссылка на ячейку хранится прямо в объекте `SignText` (он неизменяем:
  правка таблички создаёт новый объект), поэтому каждый кадр нет ни хеширования, ни поиска в map.
- **Атлас растёт страницами** (по умолчанию 1024×1024, до 16 страниц), упаковка «полками»
  со слиянием освободившихся отрезков. Лишние пустые страницы выгружаются из видеопамяти.
- **Масштаб x2 по умолчанию** — строки нечётной ширины не «сплющиваются», а TTF/юникод-шрифты чётче.
- **Лимит запеканий в секунду** — при входе в мир с сотнями табличек нет фриза: то, что не успело
  запечься, несколько кадров рисуется по-ванильному.
- **Обводка светящегося текста как в ванили**: вблизи — с обводкой, издалека — без (две разные ячейки).
- **§k (обфусцированный текст)** всегда рисуется ванилью, потому что он анимирован.
- **Шейдеры Iris поддерживаются** (с 1.1.0) — подробности ниже.
- **Строка на F3**: `Signum: N cells, P/16 pages 1024px x2, Q quads/s, B bakes/s, shaders on`.

## Сборка

Нужен **JDK 25**.

```
# Windows
gradlew.bat build

# Linux (CachyOS и т.п.)
./gradlew build
```

Готовый jar: `build/libs/signum-1.1.0+26.3.jar`. Fabric API не требуется — только Fabric Loader ≥ 0.19.3.

Или запушьте проект на GitHub — workflow `.github/workflows/build.yml` соберёт jar и выложит его
в артефакты сборки.

## Настройки — `config/signum.properties`

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | Главный выключатель |
| `textureScale` | `2` | Пикселей атласа на пиксель шрифта (1–4). Чётные значения — без артефактов. 1 — минимум видеопамяти |
| `atlasSize` | `1024` | Сторона страницы атласа. Одна страница = size²×8 байт VRAM (1024 → 8 МиБ) |
| `maxAtlasPages` | `16` | Предел страниц; создаются только по мере заполнения |
| `idleSeconds` | `30` | Через сколько секунд невидимая табличка отдаёт ячейку |
| `bakesPerSecond` / `bakeBurst` | `480` / `24` | Лимит новых ячеек в секунду и за один кадр |
| `disableWithShaderPack` | `false` | `true` — пока в Iris включён шейдерпак, рисовать текст по-ванильному |
| `disableWithIris` | `false` | Полностью выключаться, если установлен Iris |

## Совместимость

- **Iris (шейдерпаки)**: работает и с шейдерами. Во время кадра с шейдерпаком Iris подменяет ванильные
  шейдеры своими (gbuffers), расширяет формат вершин и переворачивает буфер глубины — запекать ячейку
  в такой момент нельзя. Поэтому на время запекания Signum переводит Iris в «ванильный» режим
  (тот же флаг `ImmediateState.bypass`, которым Iris сам пользуется для GUI), а потом возвращает всё как было,
  включая id текущей таблички (`blockEntityId`). Готовый квад рисуется уже под шейдерпаком: он проходит
  через ту же программу `gbuffers_block`, что и ванильный текст табличек, с тем же id блока, поэтому
  освещение, тени и эффекты пака применяются как обычно. В теневом проходе текст табличек не рисуется
  (так делает и сам Iris). Если версия Iris окажется несовместимой (внутренние классы переименованы),
  Signum напишет об этом в лог и при включённых шейдерах просто уступит ванили. Принудительно
  уступать ванили при шейдерах: `disableWithShaderPack=true`.
- **ImmediatelyFast**: в нём есть похожая экспериментальная опция `experimental_sign_text_buffering`
  (по умолчанию выключена). Если она включена, Signum сам отключается, чтобы не конфликтовать.
- **Sodium, Lithium, C2ME, ModernFix** и прочие — не трогают отрисовку текста табличек.

## Ограничения

- Пока на игроке эффект «Тьма», новые ячейки не запекаются (лайтмап пульсирует) — таблички
  рисуются ванилью, уже запечённые продолжают работать.
- Шрифт из ресурспака, глифы которого выше строки таблички, может обрезаться по краю ячейки.

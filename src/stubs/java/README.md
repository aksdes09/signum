Минимальные заглушки API Sodium — только то, что вызывает Signum, с теми же сигнатурами.
Нужны лишь для компиляции и **не попадают в jar** (см. `jar { exclude ... }` в build.gradle):
во время игры используются настоящие классы из установленного Sodium.
Без Sodium класс интеграции просто никогда не загружается.

Минимальные заглушки API Mod Menu и Sodium — только то, что вызывает Signum, с теми же сигнатурами.
Нужны лишь для компиляции и **не попадают в jar** (см. `jar { exclude ... }` в build.gradle):
во время игры используются настоящие классы из установленных Mod Menu / Sodium.
Если ни один из них не установлен, классы интеграции просто никогда не загружаются.
